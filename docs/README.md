# Como conhecer e usar o processo

O processo ajuda a transformar uma ideia ou materiais existentes em decisões, entregas e software com apoio de IA. Você informa o objetivo; a IA conduz o recorte solicitado e apresenta um resultado que você consegue revisar. O produto pode ter ou não funcionalidades de IA.

## Começar é uma entrada curta

Diga à IA o que você está construindo, forneça o link do [README do processo](../README.md) e peça a etapa desejada. Pode começar de uma ideia, requisitos, referências, telas, pasta ou repositório. A ativação está no topo do README.

## O que você recebe

Cada etapa entrega conteúdo revisável para uma seção de `docs/PROJETO.md` do seu produto. O mesmo documento cresce conforme pesquisa, decisões e trabalho concluído; as Issues ficam responsáveis pela fila e evidências. Sem repositório, a análise pode começar com uma saída em Markdown na conversa, identificada como ainda não salva.

O README e `framework/` contêm o que a IA deve executar. Esta documentação explica a adoção. O documento gerado pertence ao seu produto, em outro repositório ou destino autorizado. Um link não concede à ferramenta acesso, escrita ou capacidades que ela não possui.
